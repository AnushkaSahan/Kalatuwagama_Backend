# Kalatuwagama Backend API

Spring Boot backend for the Kalatuwagama Temple Ecosystem.

## Overview

This service provides secured REST APIs for managing temple administration data, including:

- Authentication and user management
- Temple history
- Monks
- Events
- Gallery items
- Donation information
- Contact messages
- Announcements
- Daham Pasala teachers and students
- Foundation projects

## Tech Stack

- Java 21
- Spring Boot 3.2.1
- Spring Security (JWT)
- Spring Data JPA (Hibernate)
- PostgreSQL
- Flyway
- MapStruct
- Lombok
- Springdoc OpenAPI (Swagger UI)

## Prerequisites

- JDK 21
- Maven 3.9+
- PostgreSQL 14+ (or compatible)

## Configuration

Main configuration file: `src/main/resources/application.yml`

Current defaults:

- Database URL: `jdbc:postgresql://localhost:5432/kalatuwagama_db`
- Database username: `postgres`
- Database password: `12345`
- JWT secret: from env var `JWT_SECRET`, fallback value in config
- Swagger UI path: `/swagger-ui.html`
- OpenAPI docs path: `/api-docs`

Before production deployment:

- Replace database credentials
- Set a strong `JWT_SECRET`
- Restrict CORS origin(s)

## Run Locally

From this folder:

```bash
mvn spring-boot:run
```

Or build and run:

```bash
mvn clean package
java -jar target/temple-backend-1.0.0.jar
```

## Run Tests

```bash
mvn test
```

## API Documentation

When the app is running:

- Swagger UI: `http://localhost:8080/swagger-ui.html`
- OpenAPI JSON: `http://localhost:8080/api-docs`

## Authentication

Public endpoints:

- `POST /api/auth/register`
- `POST /api/auth/login`

All other API routes require a bearer token.

Send header:

```http
Authorization: Bearer <jwt-token>
```

Login response format:

```json
{
  "token": "<jwt>",
  "email": "admin@example.com",
  "role": "ADMIN"
}
```

## CORS Notes

Security configuration currently allows `http://localhost:5173` for frontend development.

If your frontend runs on a different origin, update CORS settings in `SecurityConfig`.
